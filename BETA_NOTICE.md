# Beta notice

These downloads are public development prereleases, not V1 production releases.

- Personal-data schemas and backup formats may change before V1. Export useful notes and keep independent copies. Beta upgrades, downgrades and historical backups have no blanket compatibility guarantee.
- Windows installers are unsigned. Beta.8 also provides experimental Apple silicon/Intel DMGs with ad-hoc signatures and no notarization, plus an Ubuntu 24.04 x64 package without a release-key signature. Checksums provide integrity checking, not publisher authentication.
- Beta.8 has local installed Windows read/search, edition/comparison, note restart/export, theme/language, toolbar and failed-save/close recovery evidence. This is bounded testing, not a claim that all environments or accessibility needs are qualified.
- Independent fluent Afaan Oromo/editorial review, native screen-reader review, clean-host/prerequisite-absence checks and final platform qualification remain open.
- Mac and Ubuntu packages are available for peer testing under the owner’s experimental beta decision, not qualified platform releases. Real-device Gatekeeper, GNOME/Wayland, accessibility and clean-host testing remain open. See [the testing guide](TESTING_GUIDE.md).
- Editions have distinct wording, source identities and versification. Comparison is not a reviewed verse-alignment dataset.
- KJV has a United Kingdom printing-rights caveat. See the [licensing information](LICENSING.md).
- Beta.1–beta.7 are historical downloads with different features. Beta.4 includes experimental online integration removed in beta.5; do not rely on its remote services.

Beta.8 includes the contextual highlight redesign and independent palette/appearance settings. Windows bytes are unchanged by the experimental platform addition. Native packages include completed supplemental license texts. Use the checksum for the exact platform filename to identify the published build. Two browser checks remain unresolved: palette-dialog contrast and intermittent local Scripture quote suggestions.
