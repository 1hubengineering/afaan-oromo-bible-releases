# Changelog

All listed versions are Windows x64 development prereleases. Historical downloads are retained for reference; beta.8 is recommended. Local build dates are not implied by the date these files were uploaded to GitHub.

## 0.1.0-beta.8

Corrected duplicate and comparison version selectors. The final local beta.8 toolbar update removes the Read Bible mode icon, makes Notes/Bookmarks toggle back to reading, and adds the persistent EN/OR interface toggle. Includes the beta.7 reader and themes.

[Download and verification files](https://github.com/1hubengineering/afaan-oromo-bible-releases/releases/tag/v0.1.0-beta.8).

## 0.1.0-beta.7

Refreshed the reader and responsive search controls; added Sepia and Midnight appearance choices alongside Light, Dark and System.

[Download and verification files](https://github.com/1hubengineering/afaan-oromo-bible-releases/releases/tag/v0.1.0-beta.7).

## 0.1.0-beta.6

Added three separate offline editions (gaz 2022, OOCS 2024 and KJV), chapter-following comparison, edition-specific annotations and numbered search pages. NIV and the planned 1997 Afaan Oromo edition remain unavailable.

[Download and verification files](https://github.com/1hubengineering/afaan-oromo-bible-releases/releases/tag/v0.1.0-beta.6).

## 0.1.0-beta.5

Removed the experimental online integration. Added the gaz 2022 Western Oromo offline edition, complete working Afaan Oromo and English interfaces, improved local search, and document-level source notices on exports.

[Download and verification files](https://github.com/1hubengineering/afaan-oromo-bible-releases/releases/tag/v0.1.0-beta.5).

## 0.1.0-beta.4

Updated reader and licensed UI compositions. This historical build includes experimental online integration that was removed in beta.5; those services are not guaranteed to remain available.

[Download and verification files](https://github.com/1hubengineering/afaan-oromo-bible-releases/releases/tag/v0.1.0-beta.4).

## 0.1.0-beta.3

Expanded reader navigation, paged keyword search, rich note editing, local Scripture insertion, and Markdown, Word and PDF note exports.

[Download and verification files](https://github.com/1hubengineering/afaan-oromo-bible-releases/releases/tag/v0.1.0-beta.3).

## 0.1.0-beta.2

Book-name, alias and code filtering; testament filters; independently collapsible book groups and chapter navigation.

[Download and verification files](https://github.com/1hubengineering/afaan-oromo-bible-releases/releases/tag/v0.1.0-beta.2).

## 0.1.0-beta.1

Initial owner-approved Windows beta with the OOCS 2024 offline corpus, reading, search and personal annotations. English interface fallback.

[Download and verification files](https://github.com/1hubengineering/afaan-oromo-bible-releases/releases/tag/v0.1.0-beta.1).
