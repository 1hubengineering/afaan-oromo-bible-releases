# Contributing

This repository accepts reproducible bug reports and suggested corrections to public user documentation. Follow [SUPPORT.md](SUPPORT.md) and keep reports respectful, concrete and free of private data.

Application source is maintained privately. A public release or documentation repository does not grant access to that source or permission to republish proprietary components. Do not submit Bible text, paid UI source or other third-party material unless you can document the relevant rights and attribution.

For wording feedback, identify the current interface language, exact label and proposed correction. Scripture corrections must identify the edition and authoritative source; application maintainers must not silently rewrite published translation text.
