# Afaan Oromo Bible

[Visit the website](https://bible.1hubengineering.com/) · [Afaan Oromoo](https://bible.1hubengineering.com/om/)

An independent desktop Bible reader with offline Scripture, search and personal study tools.

**Public beta. Recommended Windows version: 0.1.0-beta.8. Experimental Mac and Ubuntu downloads are available for testing.** These are development builds, not the final V1 release. Back up useful notes before installing or changing versions.

[Download the recommended Windows installer](https://github.com/1hubengineering/afaan-oromo-bible-releases/releases/download/v0.1.0-beta.8/Afaan-Oromo-Bible-0.1.0-beta.8-x64-setup.exe) · [Release notes and checksums](https://github.com/1hubengineering/afaan-oromo-bible-releases/releases/tag/v0.1.0-beta.8) · [All beta versions](https://github.com/1hubengineering/afaan-oromo-bible-releases/releases)

[Test on macOS or Ubuntu](TESTING_GUIDE.md) — choose Apple silicon, Intel Mac or Ubuntu 24.04 x64. These experimental builds have signing and qualification limits.

## What you can do in beta.8

- Read gaz 2022 (Western Oromo), OOCS 2024 and KJV locally.
- Compare editions by book and chapter; chapter correspondence does not establish verse-by-verse equivalence.
- Search within an edition, narrow by book or testament, and navigate numbered result pages.
- Highlight wrapped Scripture text and use its contextual color/note/bookmark/copy toolbar independently in either reading pane.
- Save bookmarks and personal notes; export individual notes as Markdown, Word or PDF.
- Export and restore a JSON backup of personal records.
- Choose an Afaan Oromo or English interface. Select Classic, Sepia, Midnight, Forest or Plum independently of Light, Dark or Follow system appearance.

NIV and the planned 1997 Afaan Oromo edition are unavailable. Disabled selector entries explain availability; their texts are not bundled.

## Install and use

Read the [installation and update guide](INSTALLATION.md), [user guide](USER_GUIDE.md), [beta limitations](BETA_NOTICE.md), and [changelog](CHANGELOG.md).

Windows installers are **unsigned / NotSigned**. Experimental Mac builds are ad-hoc signed without Developer ID/notarization; Linux packages have no release-key signature. SHA-256 checks detect file changes; they do not establish publisher identity. WebView2 may require an internet download during installation if it is missing. Beta.8 reads, searches, annotates and exports local content offline after prerequisites are installed.

Windows 11 x64 has local installed-app test evidence. No broader Windows support floor is claimed. macOS and Linux remain unqualified release targets; beta.8 now includes explicitly experimental test downloads and a [device testing guide](TESTING_GUIDE.md).
