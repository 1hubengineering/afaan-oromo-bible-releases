# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/1hubengineering/afaan-oromo-bible-releases/security/advisories/new) for suspected security vulnerabilities. Do not open a public issue containing an exploit, personal data or credentials.

Include the affected version, a minimal reproduction, likely impact and any safe workaround. Use synthetic notes or redacted samples. Never submit a real personal-data backup as a reproduction.

The newest beta is the active development target. Older betas are historical downloads and do not receive a maintenance guarantee. No response-time commitment is made.

Installers are currently unsigned. Verify the exact asset's SHA-256 against the release checksum file; a matching checksum does not establish publisher identity. No mechanism for automatic update delivery is promised by this repository.
