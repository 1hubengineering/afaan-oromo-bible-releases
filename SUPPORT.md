# Troubleshooting and bug reports

Check the [installation guide](INSTALLATION.md) and [known beta limitations](BETA_NOTICE.md) first. Use the recommended beta before reporting a problem unless the issue specifically concerns a historical version.

For a reproducible defect, open an [issue](https://github.com/1hubengineering/afaan-oromo-bible-releases/issues/new/choose) and include:

- App version, Windows version and architecture.
- Bible edition and passage reference if relevant.
- Steps to reproduce, expected behavior and actual behavior.
- A redacted screenshot or exact error message when useful.

Do not attach personal backups, private note databases, credentials or publisher correspondence. Report vulnerabilities privately using [SECURITY.md](SECURITY.md). No response-time or production-support commitment is made for these development betas.
