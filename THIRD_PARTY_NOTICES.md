# Third-party notices

Edition copyright, trademark, attribution and license notices are bundled with the application and accessible offline in About. The [licensing summary](LICENSING.md) identifies the editions in each beta.

- [JavaScript dependency, shadcn/ui and bundled font notices](licenses/javascript-dependencies.txt).
- [Native Windows dependency notices](licenses/native-dependencies.txt), a conservative notice inventory from the current Windows dependency graph. Historical builds can differ; inclusion is not a claim that every listed crate is shipped in every installer.
- [Apple silicon Mac native notices](licenses/native-macos-arm64.txt).
- [Intel Mac native notices](licenses/native-macos-x86_64.txt).
- [Ubuntu x64 native notices](licenses/native-linux-amd64.txt).
- [MPL-covered third-party source availability](SOURCE_INFORMATION.md).
- [Additional edition and project notices](licenses/resource-notices.md).

The JavaScript notice collection covers the current packaged production graph, including Tiptap, DOCX, pdfmake and bundled Roboto font notices. Native notices are supplied alongside the installers; dependency licenses do not grant a license to proprietary application or paid component source.

Experimental Mac/Ubuntu beta.8 packages also include their complete target notice text in the installed application resources. The release’s THIRD_PARTY_NOTICES.zip contains all platform notices and the unmodified MPL source archives identified above. The target inventories include normal/build dependency closures as a conservative superset, not a claim every listed package is present in every final executable.
