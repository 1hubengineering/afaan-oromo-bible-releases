# User guide — beta.8

## Read and compare

Choose a book and chapter from navigation. The version selector changes the Bible edition; the EN/OR control changes the interface language independently. Use the comparison control to open a second edition. Comparison follows book/chapter labels and does not assert that individual verse numbering or wording aligns exactly.

## Search

Enter a word, phrase or supported reference in search. Choose an edition and optional book/testament scope. Open a result to navigate to its passage; use the numbered controls to move between result pages. Results belong to the selected edition.

## Personal study

Select verses to use available bookmark, highlight and note actions. Notes and bookmarks retain their original edition references; changing editions does not reassign them to different wording. Notes and Bookmarks toolbar controls open their workspaces; selecting the active control returns to reading. Preserve a draft if saving reports a failure, then retry before closing.

The note editor supports the provided formatting and local Scripture insertion controls. Export an individual note as Markdown, Word or PDF using its export action. Exported notes are separate from a complete personal-data backup. Required Scripture notices accompany supported exports.

## Backups

Use the app's backup controls to export a JSON backup of personal records. The backup does not bundle the immutable installed Scripture library; deliberately inserted quotations remain part of authored notes. Keep the file private because it contains personal writing.

Restoring a backup replaces current personal records after validation and confirmation. Export your current records first. The application creates the defined recovery snapshot before replacement, but a separate copy remains useful. Do not assume a backup from one beta will work in another.

## Appearance and source information

Reading preferences include text and appearance controls. About provides installed edition, copyright and license information. Bible-edition licensing is separate from software and personal-note ownership.
