DEEBIIWWAN SI GARGAARAN

Interneetii malee itti fayyadamuu nan dandaʼaa?

Eeyyee. Sagantaa kanaa fi wantoota inni itti hojjechuuf barbaadu erga feʼattee booda, dubbisuu, barbaaduu, maxxansoota wal bira qabuu, yaadannoo barreessuu fi faayila godhanii baasuun kompiitara kee irratti hojjetu. Herrega fayyadamaa hin barbaadan. Yeroo jalqabaatiif feʼuuf, Windows WebView2 yookaan sagantaalee sirnaa Linux barbaachisan buufachuuf interneetiin barbaachisuu dandaʼa. Kompiitara qophii duraa hin qabne irratti interneetii malee feʼumsa jalqabaa raawwachuun ammallee guutumaan hin mirkanoofne.

Feʼuu koo dura maal beekuun qaba?

Beta Windows, Windows 11 x64 irratti yaalameera; Microsoft Edge WebView2 barbaada. Paakeejiiwwan Mac kan Apple silicon fi Intel addaan qophaaʼaniiru; macOS 14 yookaan isa boodaa irratti akka hojjetaniif qophaaʼan. macOS 15 irratti yaaliin banamuu jalqabaa godhameera; kun garuu sirna sana irratti guutumaan akka hojjetan mirkaneessuu miti. Yaaliin Linux Ubuntu 24.04 x64 irratti xiyyeeffata; GTK3/WebKitGTK 4.1 barbaada.

Paakeejiiwwan Windows fi Linux mallattoo dijitaalaa hin qaban; maxxansoonni Mac mallattoo ad-hoc qabu, garuu mirkaneessa Apple (notarization) hin qaban. Feʼuu kee dura qajeelfama feʼumsaa fi qajeelfama yaalii sirna kompiitaraa dubbisi. Koodonni sakattaʼiinsaa (checksums) faayiloonni jijjiiramuu isaanii adda baasuuf gargaaru; eenyummaa qaama faayilicha maxxanse hin mirkaneessan.

Maxxansoonni Kitaaba Qulqulluu kam faʼatu keessatti argamu?

Beta kun gaz 2022 (Afaan Oromoo Dhihaa), OOCS 2024 fi King James Version Afaan Ingilizii of keessaa qaba. Maxxansoonni kun kompiitara kee irratti kuufamu. NIV fi maxxansi Afaan Oromoo bara 1997 karoorfame keessatti hin hammatamne. Afaan ittiin saganticha fayyadamtu jijjiiruun maxxansa Kitaaba Qulqulluu dubbisaa jirtu hin jijjiiru.

Ulaagaalee itti fayyadama maxxansa tokkoon tokkoo beekuuf odeeffannoo maddootaa fi hayyama maxxansootaa ilaali.

Yaadannoowwanii fi mallattooleen dubbisaa koo eessatti kuufamu?

Galmeewwan dhuunfaa kee kompiitara kee irratti, kuusaa Kitaaba Qulqulluu saganticha waliin dhufu irraa addaan kuufamu. Hojiileen ijoo herrega fayyadamaa yookaan sarvara interneetii irratti hojjetu hin barbaadan. Sagantichi galmeewwan cloud waliin wal-simsiisuu hin deeggaru. Yaadannoowwan faayila godhattee baafattu fi koppiiwwan kuusaa barreeffama dhuunfaa qabaachuu dandaʼu; kanaaf of eeggannoodhaan kuusi fi qoodi. Saganticha haquun galmeewwan dhuunfaa fi faayiloota baafatte hunda haquu dhiisuu dandaʼa.

Ibsa dabalataa beeksisa iccitii dhuunfaa keessatti argatta.

Galmeewwan qorannoo koo akkamittan koppii kuusaa godhadha?

Meeshaa koppii kuusaa galmeewwan dhuunfaa sagantichaa fayyadamuun galmeewwan kee faayila JSON godhii baasi; koppii adda taʼes kuusi. Yaadannoowwan tokko tokko PDF, Word yookaan Markdown godhii baasuu ni dandeessa; yaadannoo tokko faayila godhanii baasuun koppii kuusaa galmeewwan dhuunfaa hundaatiif bakka hin buʼu. Koppii kuusaa deebisanii galchuun, erga faayilichi sakattaʼamee fi ati mirkaneessitee booda, galmeewwan dhuunfaa amma jiran bakka buusa; kanaaf galmeewwan ammaa dursee baasi. Koppiin kuusaa beta tokkoo beta biraa waliin akka hojjetu wabii hin qabu.

Qajeelfama koppii kuusaa gochuu fi deebisanii galchuu qajeelfama fayyadamaa keessatti kenname hordofi.

Dubbisaa kanaaf “beta” jechuun maal jechuudha?

Dubbisaan kun ammallee fooyyaʼaa jira. Afaanii fi gulaalli isaa irra deebiʼamanii ilaalamaa jiru. Akkasumas, namoota hundaaf mijataa taʼuu isaa sakattaʼuun, kompiitara qophii duraa hin qabne irratti feʼuu fi sirnoota adda addaa irratti gahumsa xumuraa isaa mirkaneessuun itti fufeera. Maxxansoonni Mac fi Linux yaalii dha. Rakkooleen uumamuu waan dandaʼaniif, galmeewwan qorannoo barbaachisoo koppii kuusaa godhadhu.

Daangaaleen beekaman beeksisa beta keessatti ibsamaniiru. Atlas Kitaaba Qulqulluu fi meeshaaleen qorannoo balʼaan karoorfamaniiru; beta kana keessatti hin hammatamne, guyyaan itti dhiyaatanis waadaa hin galamne.

Rakkoo akkamittan gabaasa yookaan yaada fooyyaʼiinsaa kenna?

Yaaddoo jechootaa, rakkoo sagantichaa yookaan yaada fooyyaʼiinsaa nuuf qoodi. Unki yaadaa asuma banama; herrega fayyadamaa hin barbaachisu. Unki yoo hin banamne, imeelii nuuf ergi.

Yaada kee nuuf qoodi

Rakkoo sana ibsuuf kan gargaaru qofa galchi. Odeeffannoo dhuunfaa suuraalee keessaa haqi. Yaadannoowwan dhuunfaa, koppiiwwan kuusaa guutuu fi jechoota iccitii hin ergin. Gabaasoonni GitHub uummataaf mulʼatu.

Rakkoo nageenya odeeffannoo yoo taʼe, qajeelfama gabaasa nageenyaa hordofi.
